# Contributing

Thanks for your interest in improving this repository.

## How to contribute

1. Open an issue to discuss fixes or improvements.
2. Fork the repository and create a focused branch.
3. Keep changes small and scoped.
4. Open a pull request with clear context and screenshots for UI changes.

## Content guidelines

- Keep talk information accurate and verifiable.
- Use concise excerpts (2-4 sentences).
- Ensure all links (agenda, repo, slides) are valid.
- Do not include confidential or non-public material.

## Pull request checklist

- [ ] The page still renders correctly in a browser.
- [ ] New talk entries include title, event, speakers, excerpt, and links.
- [ ] Slide files are added under `assets/slides/` with clear filenames.
- [ ] Documentation is updated when behavior or structure changes.
