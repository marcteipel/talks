# Marc Teipel — Speaking Portfolio

Public speaking portfolio for Marc Teipel, AI Solution Engineer at Microsoft.

## Website

The site is a dependency-free static GitHub Page:

- `index.html` contains the complete portfolio
- `assets/logos/` contains locally hosted event logos
- `assets/slides/` contains downloadable presentation material
- `assets/marc-teipel.png` is the profile photo

Open `index.html` directly in a browser for a local preview.

## Adding a new talk

1. Copy an existing `<article class="event">` block in `index.html`.
2. Update the date, title, format, language, summary, topics, and links.
3. Add an event logo to `assets/logos/`.
4. Add slides to `assets/slides/` when available.

## Publishing

In **Settings → Pages**, select **Deploy from a branch**, then choose the publishing branch and
the repository root (`/`).
